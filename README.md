# Spa-Salon-Reservation-Website
Website responsif Salon Cantika Beauty berbasis Single Page Application (SPA). Dikembangkan menggunakan HTML5, CSS3, dan JavaScript murni pada frontend, serta PHP untuk pemrosesan backend yang terintegrasi otomatis dengan sistem penyimpanan database reservasi online berbasis spreadsheet/CSV. Cocok untuk demonstrasi fungsionalitas web dinamis.
